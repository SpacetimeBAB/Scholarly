# Scholarly (Legacy / Archived Version)

> **⚠️ Status: ARCHIVED / ABANDONED**  
> This repository contains the original, legacy codebase for **Scholarly**. This version has been deprecated and abandoned as the project has been fully migrated to a modern **Next.js and TypeScript** stack. (Login and API searches have been cycled)
> 
> *Note: The new, production-ready version of Scholarly is currently **under construction** and is not yet publicly available for viewing.*

---

## About Scholarly

Scholarly is a web-based platform designed to bridge the gap between aspiring high school student researchers and local college professors. By simplifying the discovery of academic researchers and streamlining the outreach process, Scholarly aims to make academic mentorship more accessible.

While this specific repository is no longer actively maintained, it served as the original proof-of-concept and Minimum Viable Product (MVP) used to validate the core ideas and features for my Demo Day Project for All Star Code.

---

## Features Implemented in This Version

Despite being an earlier iteration, this legacy build successfully prototyped several core features of the platform:

*   **OpenAlex API Integration:** Enabled live queries to search through millions of academic researchers and papers directly from the search interface.
*   **Interactive Login System:** Prototyped user authentication and session states.
*   **Visual Animations:** Incorporated smooth UI transitions and interactive styling to enhance user experience.
*   **About the Author Section:** Dedicated space detailing the student-founder background and the mission behind building Scholarly.
*   **Responsive UI/UX:** Built with a clean layout and aesthetic focused on academic accessibility.

---

## Tech Stack (Legacy)

*   **Markup:** HTML5
*   **Styling:** CSS3 (Custom properties, layouts, and animations)
*   **Logic:** Vanilla JavaScript (ES6+), asynchronous `fetch` requests, and debounced search handlers.
